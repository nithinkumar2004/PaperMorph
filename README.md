# 📝 PaperMorph

**PaperMorph** is a clean, modern, and responsive web application that converts PDF files into editable DOCX documents. It features file previews, success notifications, and a toggle for dark/light theme — making document conversion as smooth and stylish as possible.

## 🚀 Features

- 📄 Upload and convert PDFs to DOCX with ease  
- 🖼️ Instant preview of the selected PDF file  
- 🌗 Light and Dark mode toggle  
- ✅ Success messages and downloadable DOCX link  
- 🧼 Clean Bootstrap 5 UI with modern design

## 🛠️ Built With

- [Python](https://www.python.org/)
- [Flask](https://flask.palletsprojects.com/)
- [pdf2docx](https://pypi.org/project/pdf2docx/)
- [Bootstrap 5](https://getbootstrap.com/)
- HTML5, CSS3, JavaScript
